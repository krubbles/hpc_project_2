In this study, we compare the performance of 3 different single-threaded implementations matrix-matrix multiplication, a naive implementation, an implementation with blocking and copy optimizations, and a highly optimized reference implementation in CBLAS. We measure the observed MFLOPS of matrix-matrix multiplication for all 3 implementations across a range of matrix sizes and block sizes. The results suggest that blocking and copy optimizations substancially increase MFLOPS over the naive implementation, but do not match the performance of the highly optimized CBLAS implementation.
